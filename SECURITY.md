## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please report it responsibly.

**Please DO NOT open a public issue or pull request for security vulnerabilities.** 

Instead, please use private vulnerability reporting channels or contact us directly. Please include:
* A description of the vulnerability and its impact.
* Step-by-step instructions or proof-of-concept code to reproduce the issue.
* Affected source files or paths (such as database storage schemas or token validation regex filters).
