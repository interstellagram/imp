### 你好呀！

这个仓库旨在为在 GitHub 上 *fork*（复刻）一个仓库提供一个示例。

创建一个 *fork* 就是生成他人项目的个人副本。Fork 在原仓库与你的个人副本之间起到某种桥梁的作用。你可以提交 *Pull Requests*（拉取请求），通过向原项目提供你的更改，来帮助他人的项目变得更好。Fork 是 GitHub 社交编程的核心。

Fork 这个仓库之后，你可以对项目进行一些修改，并提交[一个 Pull Request](https://github.com/octocat/Spoon-Knife/pulls) 作为练习。

关于如何 fork 仓库的更多信息，[请查看我们的指南《Forking Projects》](http://guides.github.com/overviews/forking/)。谢谢！:sparkling_heart:
